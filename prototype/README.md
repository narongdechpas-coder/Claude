# โปรแกรมจำลอง: เคลมค่าขาดประโยชน์

ไฟล์เดียว `index.html` เปิดในเบราว์เซอร์ได้เลย ไม่ต้องติดตั้งอะไร ข้อมูลทั้งหมดเป็นข้อมูลจำลองและเก็บใน localStorage ของเบราว์เซอร์ (กด "รีเซ็ตข้อมูลจำลอง" เพื่อเริ่มใหม่)

## ลองเล่นตามลำดับ
1. **ผู้เรียกร้อง** → เริ่มยื่นคำร้อง → กดข้อมูลทดลอง "รถเก๋ง (มีสิทธิ์)" → ตรวจสอบสิทธิ์
2. OTP ทดลอง `123456` → กรอกวันซ่อม (วันรับรถคืนเลือกวันในอนาคตได้ = วันที่อู่นัด)/บัญชี → "ใช้ไฟล์ตัวอย่างทั้งหมด" → ยื่น
3. **หลังบ้านบริษัท** → เปิดคำร้อง → เอกสารครบ → เสนอยอด → อนุมัติตาม Step
4. **ผู้เรียกร้อง** → เปิดคำร้อง → ตอบรับด้วย OTP
5. **หลังบ้าน** (ตัวกรอง "งานที่ต้องทำ") → โอนเงินผ่าน API ธนาคาร (จำลอง)
6. **ผู้เรียกร้อง** → ดูหนังสือยืนยันการจ่ายเงิน

## ข้อมูลทดลอง
| เลขเคลม | ทะเบียน | ผลตรวจสิทธิ์ |
|---|---|---|
| CLM-69-004521 | 1กข 1234 | มีสิทธิ์ (รถเก๋ง 500 บาท/วัน) |
| CLM-69-004588 | 30-4567 | มีสิทธิ์ (รถตู้ 700 บาท/วัน) |
| CLM-69-003910 | 2กง 4455 | ไม่มีสิทธิ์ (เป็นฝ่ายผิด) |
| CLM-69-004102 | 6กท 9001 | ยื่นไปแล้ว |

- เลขบัญชีลงท้าย `0000` → จำลองธนาคารปฏิเสธการโอน
- อำนาจอนุมัติ: ≤5,000 Step 1 · ≤20,000 Step 2 · >20,000 Step 3
- หลังบ้าน → แท็บ "รายงานผู้จัดการ": KPI, การแจ้งเตือน, งานค้าง, สายอนุมัติ, อู่ห้างเทียบอู่นอก และคะแนนอู่ (มีข้อมูลย้อนหลังจำลองประมาณ 60 เคส)
- หลังบ้าน → แท็บ "Diagram Flow": แผนภาพขั้นตอน 10 จุดตรวจ (CP1–CP10) พร้อมเงื่อนไข ผู้รับผิดชอบ SLA และจำนวนคำร้องที่อยู่แต่ละจุดตอนนี้ กดที่กล่องเพื่อดูรายละเอียด
- หลังบ้าน → แท็บ "รายงานผู้จัดการ" → ออกรายงานประจำวัน (เลือกวันที่) และประจำเดือน (เลือกเดือน) ดูเป็นเอกสาร ดาวน์โหลดเป็น Excel (.xlsx) แยกชีต (เฉพาะหน้าที่เผยแพร่) หรือคัดลอกไปวางใน Excel / Google Sheets
